## Desafio Controle de Fluxo

Desafio sobre Controle de Fluxo da DIO, proposto pelo professor Gleyson Sampaio.

## Elaboração do Projeto

Foram feitos dois parâmetros via terminal que representam dois números inteiros, onde, na execução do código apresenta a impressão do "número inteiro 1" ao "número inteiro 2". Apresentando exceções caso não seja informado nenhum número inteiro e para caso o "número inteiro 1" seja maior que o "número inteiro 2".
